Required · One-time setup

Drivers

Everything PlayStation and Xbox players need. Install both from the app — official Nefarius packages, one Windows approval for the whole set.

PlayStation

DualSense, DualSense Edge, DualShock 4 — ViGEmBus + HidHide.

Xbox

Xbox One, Series, Elite — same two drivers. Windows already reads the pad.

PlayStation Xbox

ViGEmBus

Creates the virtual pad games read — PlayStation and Xbox layouts. Required for every macro.

HidHide

Hides your physical DualSense, DualShock, or Xbox pad so games only see the virtual controller — no double input.

Live control Cloak Off

Cloak arms automatically when your pad connects so macros reach the game. Turn it off only if you want the physical pad visible.

Both drivers install together with a single Windows approval. No extra PlayStation or Xbox driver packs are required. A reboot is sometimes needed after HidHide.
